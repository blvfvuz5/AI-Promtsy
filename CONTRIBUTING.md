# Contributing to pr0mtsy

Thanks for your interest. This guide explains how to contribute.

## Reporting Issues

Before creating an issue, check if it already exists.

A good issue includes:

- Clear description of the problem
- Which LLM you used
- Steps to reproduce
- Expected vs. actual behavior

## Pull Requests

1. Fork the repository.
2. Create a feature branch.
3. Commit using Conventional Commits.
4. Open a pull request against `main`.

## Style Guide

- Plain Markdown, no emojis
- English for the prompt itself
- English for all documentation

## Testing

Since this is a single-prompt repository, test your changes by:

1. Pasting the modified prompt into a fresh chat.
2. Running through the question round.
3. Verifying skip commands work as expected.
4. Checking that no emojis appear in output.
